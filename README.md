Entry for the [One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun: exactly one word — the word a grandma would text about AI.

## The word

**doohickey** — the classic grandma word for a thing she doesn't know the name of, which is exactly how a grandma would refer to AI: warm, a little baffled, and funny in a single word.

## How it works

`main.ts` (Node 22 stdlib only, no network, no dependencies) copies `entry.txt` byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is exactly one word, 9 characters, no trailing newline.
